# Stock Management — prototype

A one-page mock-up of a pharmacy stock sheet. It was my first sketch of the layout before I built the full stock systems.

**Live page:** https://hlaolil.github.io/stock/

## What it shows

- **Dashboard**: a placeholder for the stock overview and alerts.
- **Stock table**: the columns the stock sheet uses (item, carried over, used, balance, reorder level and quantity to order), with two sample rows.
- **Update stock**: a form for recording the quantity used.

This is HTML and CSS only (`index.html`, `styles.css`). The form does not save anything yet.

## Where this went

The working versions are:

- [HealthRecords](https://github.com/hlaolil/HealthRecords): the clinic pharmacy system (Flask and MongoDB)
- [healing-hub-stock](https://github.com/hlaolil/healing-hub-stock): stock and point of sale for The Healing Hub Pharmacy
